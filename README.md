# Текстовый калькулятор

Калькулятор арифметических выражений, записанных словами на русском языке.  
Пример: `двадцать пять плюс тринадцать` → `тридцать восемь`.

## Поддерживаемые возможности

- Числа словами от 0 до 99, десятичные дроби до миллионных.
- Операции: `плюс`, `минус`, `умножить`, `разделить`, `остаток от деления`, `в степени`.
- Скобки, приоритет операций, отрицательные числа, `минус минус`.
- Тригонометрия: `синус`, `косинус`, `тангенс`, константа `пи`.
- Десятичный разделитель — слово `и`: `пять и пять десятых`.
- Вывод результата словами: целые, конечные десятичные дроби, периодические дроби (период до 4 знаков), округление до тысячных.
- Диагностика ошибок на русском: неизвестное слово, неверная запись числа, неверная последовательность, деление на ноль, остаток от деления на ноль, дисбаланс и вложенность скобок, недопустимые степени и тригонометрия.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа. Бесконечный цикл: ввод → `calc` → вывод. Ошибки печатаются, цикл продолжается. Также содержит `calc(text) -> str`. |
| `errors.py` | Иерархия исключений: `CalculatorError` → `TokenizeError`, `EvalError` и конкретные подклассы. Все сообщения на русском. |
| `tokens.py` | Типы токенов, коды операций, классы `Number`, `Operator` и наследники, `OpenBracket`, `CloseBracket`, `DecimalSep`. |
| `converter.py` | Словари `to_code` (слова → коды) и `to_str` (числа → слова для вывода). Функция `get_object_info`. |
| `tokenizer.py` | Лексический разбор: слова → токены. Склейка многословных фраз, сборка десятичных дробей, классификация ошибок. |
| `rpn_builder.py` | Синтаксические проверки и построение обратной польской записи за один проход. |
| `evaluator.py` | Вычисление ОПЗ. Точная арифметика через `Fraction`, проверки деления/модуло/степеней/тригонометрии. |
| `formatter.py` | Преобразование `Number` в строку словами: целая часть, конечные и периодические дроби, округление. |

## Разделение ответственности

**Миша:**
- `rpn_builder.py`
- `formatter.py`
- часть `converter.py`, относящаяся к `formatter`: словари `number_to_word`, `number_to_word_feminine`, `hundreds_to_word`, `denominator_to_words`

**Даня:**
- `main.py`
- `errors.py`
- `tokens.py`
- `converter.py` (кроме `to_str`-словарей)
- `tokenizer.py`
- `evaluator.py`
